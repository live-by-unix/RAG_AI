## RAG_AI
My test of RAG systems. 
This README covers tech stack, installation, usage, and licensing.    

## Tech Stack
* Python
* ChromaDB
* Ollama

## Installation
Download release, unzip
and ```cd``` into it.     
Git clone for latest

## Ussage 
Run:    
```bash
python3 rag_ingest.py
```
(replace fill in the blanks in file before running)     
Then run:     
```bash
python3 rag_chat.py
```
Just a template you can change
